    Approximate level matching only turns louder previews down. Quieter variations stay quiet. Turn it off to compare the original levels. This applies only to previews; reading uses your chosen volume.
    Reading passage
    Each preview lasts 16 seconds, using the same passage, seed and musical starting point. Differences describe settings; choose what sounds comfortable.
    When combining parents, the first selected starting point supplies the musical recipe; the other parents contribute preference traits.
