# Classical starting points and chapter development

Implemented 31 October 2026. This is a small hand-authored design library, not a classical generator trained on scores. It puts the [literature findings](classical-inspiration.md) into executable recipes and inspectable text rules. No reference recording or note-for-note score transcription is included.

## Listen and choose

Open **Shape your soundtrack → Classical-inspired starting points** in the reader. Choose any of the nine directions, then **Use classical direction**, or preview six alternatives with **Compare classical directions**. Changing the dropdown alone does not change playback. The comparison starts from the selected part of the library; choose another starting point to compare the remaining entries. Existing pins, numeric evolution, undo, named favourites and profile downloads retain the direction and development policy.

The standalone explorer generated by `python tools/exploration_page.py` now has a **Classical-inspired nine** set alongside the broad and Bach sets. Each card holds its recipe for a fair comparison; its profile can be brought into the reader. Choose chapter development in the reader to enable the automatic route. **Warm ensemble · synthesised** keeps the recipe's intended instruments; other palettes reinterpret them.

| Direction | Original musical implementation | Chord pacing |
|---|---|---|
| Bach-inspired flowing line | Pedal bass, continuous neighbour figure, bowed upper roles | 1 bar |
| Bach-inspired minor cycle | Moving bass, minor figuration | 1 bar |
| Bach-inspired dialogue gaps | Felt keys, rests and closing breaths | 1 bar |
| Vivaldi-inspired spring calls | Separated flute calls and a thinner answer | 1 bar |
| Vivaldi-inspired storm motion | Short bowed attacks and a four-bar swell | 1 bar |
| Vivaldi-inspired winter pulse | Repeated dry plucks over a pedal | 2 bars |
| Vivaldi-inspired winter shelter | Sparse sustained bowed line | 2 bars |
| Chopin-inspired quiet elegy | Slow felt-key chordal support and repeated gestures | 4 bars |
| Corelli-inspired call and space | Active guitar figures followed by a thinner answer | 1 bar |

The executable [classical-knowledge.json](classical-knowledge.json) contains exact cycles, programme/analysis references, original adaptation descriptions and cue parameters. For example, the elegy uses an original diatonic minor cycle; it does not reproduce Chopin's chromatic harmony. Major/minor choices and exact figures are Awen proposals. The common clock remains 72 BPM in 4/4; diversity here comes from attack spacing, duration, harmonic pacing, articulation and phrase shape. Triple meter, independent counterpoint and rich chromatic suspensions are still future work.

## What text changes

| Matched evidence (examples) | Gentle change within a chapter | Candidate at the next chapter |
|---|---|---|
| Thunder, lightning, explosion, black powder | Shorter articulation; retain motion | Storm motion |
| Chase, fled, pursuit, dodged | Continuous motion at the same tempo | Storm motion |
| Frozen, snow, shivering | Drier attacks | Winter pulse |
| Fireside, shelter, warmth | Longer notes and fewer upper attacks | Winter shelter |
| Grief, mourned, sorrow | Sparse upper activity | Quiet elegy |
| Birds, blossom, meadow | Separated calls | Spring calls |
| Said, replied, whispered | More upper-register space | Dialogue gaps |
| Wonder, discovered, astonished | Connected figuration | Flowing line |
| No strong match | Retain expression baseline | Return to the chosen home recipe |

The UI shows the matched words and mapping. Rules match whole tokens/phrases, count distinct matches and suppress matches following simple local negation. More matches win; library order breaks ties. There is no stemming, semantic model, irony detection or learned emotional truth. Ambiguous words and mixed passages can yield an unsuitable suggestion. A season name alone does not mandate a mood. Paragraph expression uses gradual gate/density changes; existing smoothed text features still influence the mixer. Resolving neighbours and the bass remain protected from optional upper-note thinning.

## Development modes and continuity

- **Hold this direction:** keep the selected recipe and home tonal region. Existing general soundtrack expression still follows the main Follow the story/Steady ambience control.
- **Follow text gently:** keep that recipe and region, while the cue mapping gradually shapes articulation and space.
- **Develop between chapters:** use the same gentle expression, and allow a new recipe/tonal region after a chapter changes. Activating a direction starts with the chosen home recipe, even when reading a later chapter. Later chapter choices use the current passage when the next four-bar boundary arrives; this is not an analysis of an entire unseen chapter.

The tonal route repeats home → subdominant region (+5 semitones) → dominant region (+7) → home by absolute chapter index. It is deterministic and independent of reading speed. The selected recipe supplies the major/minor colour. At a new chapter the first chord of that recipe begins at the next four-bar boundary, with the existing two-second sustained-harmony crossfade. The score cursor, clock and audio graph continue. A jump skips to the target chapter's region rather than replaying intervening chapters. A long held-chord recipe can be left before its full cycle closes; a composed cadential bridge is future work.

Only chapter changes or explicit user choices may replace the recipe/tonal region. A dramatic paragraph in the same chapter changes expression, not the whole piece. Chapter choice uses keyword evidence from the passage being read at the boundary. A manually selected harmony library overrides automatic chord pitches and pacing; the classical figure/texture still plays. Returning to starting-point harmony restores the classical cycle.

The policy is versioned in `genome.classical`; the composer checkpoint records active recipe, chapter, local cycle epoch, tonal offset and smoothed expression. Checkpoint identity includes the policy, and invalid state restarts safely. Composer version is `awen-score-5`. Old DSL v1 sources gain default texture/hold/shape fields; incompatible older composer checkpoints restart. Canonical source and policy survive profile/pin/export and numeric evolution. Editing/applying a raw DSL deliberately exits automatic chapter direction; undo restores it.

## Maintenance and validation

`python tools/compile_classical.py` embeds the JSON in `index.html`; `--check` verifies it matches. This is an authoring utility, not a required build step: the committed reader runs directly with inline code and no model/network dependency. New library behaviour requires a library version change and compatible import handling. Generated explorer pages preserve their embedded runtime; old experiment directories should not be overwritten.

`tests/classical.test.cjs` checks nine structurally distinct event plans, source/library consistency, legacy parser defaults, bounded durations/registers, text evidence/negation, protected neighbour resolution, chapter-only transitions, modes, deterministic restored continuation and policy/profile integrity. `tests/classical.browser.cjs` checks actual reader choices, the live graph, delayed chapter changes, saved controller reload, profile downloads/undo, native 64-second renders for all nine, evaluator continuity/signal gates, grid playback/evolution/reload and mobile layout. Synthetic feedback is marked test-only. The development renderer records active controller state in traces and accepts explicit chapter IDs/indexes from fixtures.

Automated sample checks establish audibility and digital bounds, not attractive orchestration, stylistic authenticity or reading comfort. Listen to a small matched set before widening the library or rewarding these rules with CLAP. Longer sessions, cadential bridges, section-specific score analysis, human preference calibration and better treatment of conflicting text cues remain open.
